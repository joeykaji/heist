# Interface Copy Standard

Use these conventions across all MarketBite views and the server demo.

| Text | Convention | Example |
| --- | --- | --- |
| Page and section headings | Title Case | Customer Traffic & Rushes |
| Buttons, field labels, menus, table headings | Title Case | Apply Pricing; Minimum Price |
| Short status labels | Title Case | Regular Price; Offer Unavailable |
| Instructions, descriptions, validation, and complete feedback messages | Sentence case | Hours applied. |
| Small section markers and ticker symbols | Uppercase | RUN THE SIMULATION; BUFF |

In Title Case, capitalize the first and last word and all major words. Keep articles, short prepositions, and coordinating conjunctions lowercase within a title: a, an, the, at, by, for, from, in, of, on, per, to, with, and, but, or. Capitalize both parts of a compound such as In-Person or Market-Wide. Prefer `&` for compact paired labels.

Preserve the brand slogan exactly: **Taste more. Waste less.** Keep proper names and acronyms intact: MarketBite, LinkedIn, Grubhub, TV, URL, and ET. Units retain their usual notation, such as `+5 min` and `kg`.

Use **Play / Pause**, **Restart**, **TV Display**, **Food Bundle**, and **Market Crash** consistently. Restart returns to opening and pauses. Apply buttons name what they save: Apply Hours, Apply Inventory, Apply Pricing, Apply Traffic, and Apply Deal.

Write the correct text in the source rather than using CSS to capitalize it. Preserve user-entered food names and offer names. Sentence case in explanatory prose should not change just because the same phrase also appears as a heading.
